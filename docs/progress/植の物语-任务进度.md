## 一、项目概况

**项目名称：** 植の物语（个人植物管理与识花 App）  
**产品定位：** 面向新手和进阶用户的智能养花助手，覆盖识花、植物管理、养护提醒、日记、诊断、百科与成就。  
**当前实际阶段：** Sprint A–F、Sprint G 第 1–6 切片及 Flutter Web 公网 Demo 第 1–3 切片已完成；NestJS 后端已具备 7 个测试套件、88 个可重复测试用例；Flutter Web 已完成 Auth/Garden/Reminders/Recognition 四条主链路的真实 Nest API 联调与第一轮清新卡片式 UI 还原；Web refresh-token HttpOnly Cookie 后端边界、Flutter Web 客户端接入、业务 401 自动刷新和 App 启动静默恢复登录态均已落地，且已完成真实浏览器刷新/重开/登出恢复闭环验证；另已建立独立的公开 Flutter Web Demo 模式，无需登录即可体验花园和养护提醒，Demo 植物支持添加、删除，Demo 提醒支持创建、完成打卡，数据均通过浏览器 localStorage 持久化；Garden/Reminders 已完成非空列表态真实数据联调；Recognition 已完成图片选择、识别结果展示以及“添加到我的花园”真实创建闭环；Android 相机权限声明和移动端安全存储代码已接入，Web 构建与客户端测试通过；真实 Android/iOS 运行验证仍受本机环境阻塞；Flutter Demo 已完成代码构建，但尚未替换 Vercel 当前静态 H5 部署产物；生产后端部署仍未完成。  
**后端技术栈：** NestJS 11 + TypeScript + Prisma 7.8 + SQLite（本地开发）/ PostgreSQL（目标生产环境）。  
**外部 API：** 百度 AI 植物识别、Perenual 植物数据。  
**正式客户端：** Flutter 三端方案已决策，`client/` 工程已创建；Auth/Garden/Reminders/Recognition 已完成 Flutter Web 真实 API 联调和第一轮卡片式 UI 还原；Android/iOS 安全存储代码与 Android 相机权限声明已接入，但尚未完成真实设备运行验证、全量页面 UI 还原。
