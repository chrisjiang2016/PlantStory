## 一、项目概况

**项目名称：** 植の物语（个人植物管理与识花 App）  
**产品定位：** 面向新手和进阶用户的智能养花助手，覆盖识花、植物管理、养护提醒、日记、诊断、百科与成就。  
**当前实际阶段：** Sprint A–F、Sprint G 第 1–6 切片、Docker Compose 本地部署及 Flutter Web Demo 第 1–4 切片已完成，项目进入“可演示 Beta / 发布工程收口”阶段。NestJS 后端已实现 10 个业务模块和 44 条 HTTP 路由，历史自动化基线为 7 suites / 88 tests；但切换 PostgreSQL 后测试脚本仍传 SQLite `file:` URL，2026-08-26 的 `npm test` 在 Prisma 校验阶段失败，需先恢复测试基线。Flutter Web 已完成 Auth/Garden/Reminders/Recognition 四条真实 API 主链路及第一轮 UI，公开 Demo 已完成本地花园、提醒、示例识别和 localStorage 持久化；本次 `flutter analyze`、19 个测试和 Web release build 均通过。Android/iOS 真机仍未验证。GitHub 仓库和部署工作流已存在，但自定义 Vercel CLI 工作流失败、历史 Vercel Demo 域名无法访问，Railway 健康地址返回 404，生产部署尚未收口。

**后端技术栈：** NestJS 11 + TypeScript + Prisma 6.19.3 + PostgreSQL。

**外部 API：** 百度 AI 植物识别、Perenual 植物数据。  
**正式客户端：** Flutter 三端方案已决策，`client/` 工程已创建；Auth/Garden/Reminders/Recognition 已完成 Flutter Web 真实 API 联调和第一轮卡片式 UI 还原；Android/iOS 安全存储代码与 Android 相机权限声明已接入，但尚未完成真实设备运行验证、全量页面 UI 还原。
