# 植の物语：病虫害问题排查能力边界与文案规范（V1）

**状态：** 已确认，作为 Flutter 客户端、H5 演示和服务端接口的共同约束。  
**生效日期：** 2026-08-07

## 1. V1 对用户可承诺的能力

1. 查询病虫害知识库：按关键词、类型查看病害说明、处理建议与预防参考。
2. 创建个人排查记录：保存症状描述、可选图片链接和可选的知识库条目。
3. 查看个人排查历史与详情；记录仅本人可见。

## 2. V1 明确不提供的能力

- 不提供基于用户上传图片的自动病虫害识别。
- 不提供“AI 已确诊”“识别准确率”“自动诊断结果”等承诺。
- 不提供应用内图片上传、对象存储或相机图片直传；服务端当前仅接受合规的图片 URL 字段作为可选记录信息。
- 不提供药品/用品推荐、购买跳转或专家问诊。

## 3. 统一命名与文案

| 场景 | 使用文案 | 禁止文案 |
|---|---|---|
| 功能入口 | 病虫害问题排查 / 病虫害知识库 | AI 智能诊断 / 一拍即诊断 |
| 结果区域 | 知识库参考 / 排查建议 | 诊断结果 / 已确诊 |
| 图片说明 | 可选图片记录；当前不自动识别图片内容 | 上传照片即可自动分析 |
| 风险提示 | 建议仅供日常养护参考；严重或持续恶化请咨询专业人士 | 保证治愈 / 专业医疗式结论 |

## 4. 后续自动识别能力的准入条件

只有同时满足以下条件，才可将功能表述为“图片辅助识别”：

1. 已接入并完成评估的病虫害图像模型；
2. 已实现图片上传、对象存储、失败重试、超时和隐私告知；
3. 返回候选病害、置信度和“需用户确认”的交互，禁止把模型输出当作确定结论；
4. 有覆盖真实样本的离线评测、线上监控与降级策略；
5. PRD、Flutter 页面、H5 演示、Swagger 和客服文案同步更新。

## 5. 当前服务端映射

- `GET /api/v1/diagnosis/diseases`：知识库列表
- `GET /api/v1/diagnosis/diseases/:id`：知识库详情
- `POST /api/v1/diagnosis`：保存用户确认后的排查记录
- `GET /api/v1/diagnosis/history`：当前用户历史记录
- `GET /api/v1/diagnosis/:id`：当前用户记录详情
