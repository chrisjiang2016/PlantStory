## 二、表结构详细设计

### 2.1 用户表 `users`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `username` | VARCHAR(32) | UNIQUE, NOT NULL | 用户名（英文+数字） |
| `password_hash` | VARCHAR(255) | NOT NULL | bcrypt 哈希后的密码 |
| `nickname` | VARCHAR(64) | | 昵称，默认=username |
| `avatar_url` | VARCHAR(512) | | 头像 URL |
| `created_at` | TIMESTAMP | DEFAULT NOW() | 注册时间 |
| `updated_at` | TIMESTAMP | DEFAULT NOW() | 最后更新 |

**索引**：
- `idx_users_username` — username（唯一索引）

**业务规则**：
- 用户名只允许 `[a-zA-Z0-9]`，长度 3-32
- 密码必须包含英文和数字，长度 8-64
- 密码使用 bcrypt（cost=12）哈希存储

---

### 2.2 植物种类表 `plant_species`

> 缓存 Perenual API 数据，避免重复调用

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `perenual_id` | INTEGER | UNIQUE | Perenual 植物 ID |
| `name` | VARCHAR(128) | NOT NULL | 通用名（如"绿萝"） |
| `scientific_name` | VARCHAR(128) | | 学名 |
| `family` | VARCHAR(64) | | 科 |
| `genus` | VARCHAR(64) | | 属 |
| `watering` | VARCHAR(32) | | 浇水频率（frequent/average/minimum） |
| `sunlight` | VARCHAR(32) | | 光照需求（full_shade/part_shade/full_sun） |
| `description` | VARCHAR(1024) | | 描述 |
| `image_url` | VARCHAR(512) | | 图片 URL |
| `care_guide` | JSONB | | 完整养护指南（Perenual 原始） |
| `raw_data` | JSONB | | Perenual API 原始返回 |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |
| `updated_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_plant_species_perenual_id` — perenual_id（唯一索引）
- `idx_plant_species_name` — name（普通索引，用于搜索）

---

### 2.3 我的植物表 `my_plants`

> 用户添加到"花园"的植物实例

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `user_id` | BIGINT | FK → users.id, NOT NULL | 所属用户 |
| `species_id` | BIGINT | FK → plant_species.id, NOT NULL | 植物种类 |
| `nickname` | VARCHAR(64) | | 用户给植物起的名字 |
| `location` | VARCHAR(64) | | 摆放位置（阳台/客厅/卧室） |
| `current_stage` | VARCHAR(32) | DEFAULT 'seed' | 当前生长阶段 |
| `planted_at` | DATE | DEFAULT TODAY | 种植日期 |
| `photo_url` | VARCHAR(512) | | 植物照片 |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |
| `updated_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_my_plants_user_id` — user_id（普通索引）

**生长阶段枚举**：
- `seed` 种子期
- `sprout` 发芽期
- `seedling` 幼苗期
- `growing` 生长期
- `mature` 成熟期

---

### 2.4 识别记录表 `recognitions`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `user_id` | BIGINT | FK → users.id, NOT NULL | 所属用户 |
| `species_id` | BIGINT | FK → plant_species.id | 匹配到的植物种类 |
| `image_url` | VARCHAR(512) | | 上传的图片 |
| `confidence` | DECIMAL(5,2) | | 置信度（0-100） |
| `raw_name` | VARCHAR(128) | | 百度返回的原始名称 |
| `raw_result` | JSONB | | 百度 API 原始返回 |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_recognitions_user_id` — user_id + created_at DESC

---

### 2.5 收藏表 `favorites`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `user_id` | BIGINT | FK → users.id, NOT NULL | 所属用户 |
| `species_id` | BIGINT | FK → plant_species.id, NOT NULL | 收藏的植物种类 |
| `category` | VARCHAR(32) | | 分类标签（beginner/shade_desktop/leaf） |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_favorites_user_species` — user_id + species_id（唯一索引，防重复收藏）
- `idx_favorites_user_id` — user_id + created_at DESC

---

### 2.6 养护记录表 `care_logs`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |

| `care_type` | VARCHAR(16) | NOT NULL | 养护类型 |
| `note` | VARCHAR(255) | | 备注 |
| `performed_at` | TIMESTAMP | DEFAULT NOW() | 执行时间 |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_care_logs_user_id` — user_id + performed_at DESC
- `idx_care_logs_plant_id` — my_plant_id + performed_at DESC

**养护类型枚举**：
- `water` 浇水
- `fertilize` 施肥
- `prune` 修剪
- `repot` 换盆
- `other` 其他

---

### 2.7 生长日记表 `diaries`

| 字段 | 类型 | 约束 | 说明 |

| `content` | VARCHAR(255) | | 文字内容 |
| `image_url` | VARCHAR(512) | | 图片 URL |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_diaries_plant_id` — my_plant_id + created_at DESC

### 2.8 养护提醒表 `reminders`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | 自增主键 |
| `user_id` | BIGINT | FK → users.id, NOT NULL | 所属用户 |
| `my_plant_id` | BIGINT | FK → my_plants.id | 关联植物（可为空，自定义提醒） |
| `care_type` | VARCHAR(16) | | 养护类型 |
| `title` | VARCHAR(255) | NOT NULL | 提醒标题 |
| `remind_at` | TIMESTAMP | NOT NULL | 提醒时间 |
| `repeat_rule` | VARCHAR(16) | | 重复规则 |
| `is_completed` | BOOLEAN | DEFAULT FALSE | 是否已完成 |
| `completed_at` | TIMESTAMP | | 完成时间 |
| `created_at` | TIMESTAMP | DEFAULT NOW() | |
| `updated_at` | TIMESTAMP | DEFAULT NOW() | |

**索引**：
- `idx_reminders_user_remind_at` — user_id + remind_at（查今日提醒）
- `idx_reminders_user_completed` — user_id + is_completed

**重复规则枚举**：
- `none` 不重复
- `daily` 每天
- `weekly` 每周
- `biweekly` 每两周
- `monthly` 每月

## 三、Prisma Schema

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id             BigInt           @id @default(autoincrement())
  username       String           @unique @db.VarChar(32)
  passwordHash   String           @map("password_hash") @db.VarChar(255)
  nickname       String?          @db.VarChar(64)
  avatarUrl      String?          @map("avatar_url") @db.VarChar(512)
  createdAt      DateTime         @default(now()) @map("created_at")
  updatedAt      DateTime         @default(now()) @updatedAt @map("updated_at")

  myPlants       MyPlant[]
  recognitions   Recognition[]
  favorites      Favorite[]
  careLogs       CareLog[]
  diaries        Diary[]
  reminders      Reminder[]
  diagnoses      Diagnosis[]
  userAchievements UserAchievement[]

  @@map("users")
}

model PlantSpecies {
  id             BigInt           @id @default(autoincrement())
  perenualId     Int?             @unique @map("perenual_id")
  name           String           @db.VarChar(128)
  scientificName String?          @map("scientific_name") @db.VarChar(128)
  family         String?          @db.VarChar(64)
  genus          String?          @db.VarChar(64)
  watering       String?          @db.VarChar(32)
  sunlight       String?          @db.VarChar(32)
  description    String?          @db.VarChar(1024)
  imageUrl       String?          @map("image_url") @db.VarChar(512)
  careGuide      Json?            @map("care_guide")
  rawData        Json?            @map("raw_data")
  createdAt      DateTime         @default(now()) @map("created_at")
  updatedAt      DateTime         @default(now()) @updatedAt @map("updated_at")

  myPlants       MyPlant[]
  recognitions   Recognition[]
  favorites      Favorite[]

  @@index([name])
  @@map("plant_species")
}

model MyPlant {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  speciesId      BigInt           @map("species_id")
  nickname       String?          @db.VarChar(64)
  location       String?          @db.VarChar(64)
  currentStage   String           @default("seed") @map("current_stage") @db.VarChar(32)
  plantedAt      DateTime?        @default(now()) @map("planted_at") @db.Date
  photoUrl       String?          @map("photo_url") @db.VarChar(512)
  createdAt      DateTime         @default(now()) @map("created_at")
  updatedAt      DateTime         @default(now()) @updatedAt @map("updated_at")

  user           User             @relation(fields: [userId], references: [id])
  species        PlantSpecies     @relation(fields: [speciesId], references: [id])
  careLogs       CareLog[]
  diaries        Diary[]
  reminders      Reminder[]

  @@index([userId])
  @@map("my_plants")
}

model Recognition {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  speciesId      BigInt?          @map("species_id")
  imageUrl       String?          @map("image_url") @db.VarChar(512)
  confidence     Decimal?         @db.Decimal(5, 2)
  rawName        String?          @map("raw_name") @db.VarChar(128)
  rawData        Json?            @map("raw_data")
  createdAt      DateTime         @default(now()) @map("created_at")

  user           User             @relation(fields: [userId], references: [id])
  species        PlantSpecies?    @relation(fields: [speciesId], references: [id])

  @@index([userId, createdAt])
  @@map("recognitions")
}

model Favorite {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  speciesId      BigInt           @map("species_id")
  category       String?          @db.VarChar(32)
  createdAt      DateTime         @default(now()) @map("created_at")

  user           User             @relation(fields: [userId], references: [id])
  species        PlantSpecies     @relation(fields: [speciesId], references: [id])

  @@unique([userId, speciesId])
  @@index([userId, createdAt])
  @@map("favorites")
}

model CareLog {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  myPlantId      BigInt           @map("my_plant_id")
  careType       String           @map("care_type") @db.VarChar(16)
  note           String?          @db.VarChar(255)
  performedAt    DateTime         @default(now()) @map("performed_at")
  createdAt      DateTime         @default(now()) @map("created_at")

  user           User             @relation(fields: [userId], references: [id])
  myPlant        MyPlant          @relation(fields: [myPlantId], references: [id])

  @@index([userId, performedAt])
  @@index([myPlantId, performedAt])
  @@map("care_logs")
}

model Diary {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  myPlantId      BigInt           @map("my_plant_id")
  content        String?          @db.VarChar(255)
  imageUrl       String?          @map("image_url") @db.VarChar(512)
  createdAt      DateTime         @default(now()) @map("created_at")

  user           User             @relation(fields: [userId], references: [id])
  myPlant        MyPlant          @relation(fields: [myPlantId], references: [id])

  @@index([myPlantId, createdAt])
  @@map("diaries")
}

model Reminder {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  myPlantId      BigInt?          @map("my_plant_id")
  careType       String?          @map("care_type") @db.VarChar(16)
  title          String           @db.VarChar(255)
  remindAt       DateTime         @map("remind_at")
  repeatRule     String?          @map("repeat_rule") @db.VarChar(16)
  isCompleted    Boolean          @default(false) @map("is_completed")
  completedAt    DateTime?        @map("completed_at")
  createdAt      DateTime         @default(now()) @map("created_at")
  updatedAt      DateTime         @default(now()) @updatedAt @map("updated_at")

  user           User             @relation(fields: [userId], references: [id])
  myPlant        MyPlant?         @relation(fields: [myPlantId], references: [id])

  @@index([userId, remindAt])
  @@index([userId, isCompleted])
  @@map("reminders")
}

model Diagnosis {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  pestDiseaseId  BigInt?          @map("pest_disease_id")
  imageUrl       String?          @map("image_url") @db.VarChar(512)
  symptomDesc    String?          @map("symptom_desc") @db.VarChar(255)
  rawData        Json?            @map("raw_data")
  createdAt      DateTime         @default(now()) @map("created_at")

  user           User             @relation(fields: [userId], references: [id])
  pestDisease    PestDisease?     @relation(fields: [pestDiseaseId], references: [id])

  @@index([userId, createdAt])
  @@map("diagnoses")
}

model PestDisease {
  id             BigInt           @id @default(autoincrement())
  perenualId     Int?             @unique @map("perenual_id")
  name           String           @db.VarChar(128)
  scientificName String?          @map("scientific_name") @db.VarChar(128)
  type           String?          @db.VarChar(32)
  description    String?          @db.Text
  treatment      String?          @db.Text
  imageUrl       String?          @map("image_url") @db.VarChar(512)
  rawData        Json?            @map("raw_data")
  createdAt      DateTime         @default(now()) @map("created_at")

  diagnoses      Diagnosis[]

  @@map("pest_diseases")
}

model Achievement {
  id             BigInt           @id @default(autoincrement())
  code           String           @unique @db.VarChar(64)
  name           String           @db.VarChar(64)
  description    String?          @db.VarChar(255)
  icon           String?          @db.VarChar(64)
  conditionType  String?          @map("condition_type") @db.VarChar(32)
  conditionValue Int?             @map("condition_value")
  createdAt      DateTime         @default(now()) @map("created_at")

  userAchievements UserAchievement[]

  @@map("achievements")
}

model UserAchievement {
  id             BigInt           @id @default(autoincrement())
  userId         BigInt           @map("user_id")
  achievementId  BigInt           @map("achievement_id")
  unlockedAt     DateTime         @default(now()) @map("unlocked_at")

  user           User             @relation(fields: [userId], references: [id])
  achievement    Achievement      @relation(fields: [achievementId], references: [id])

  @@unique([userId, achievementId])
  @@map("user_achievements")
}
```
