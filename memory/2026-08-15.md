## 🔧 关键修复记录

### 问题 1：Prisma 7.8.0 不兼容

**错误**：
```
Error validating datasource `db`: The preview feature `url` is not known.
```

**原因**：Prisma 7 不再支持 `url = env("DATABASE_URL")` 语法

**解决**：降级到 Prisma 6.19.3
```bash
npm install prisma@6 @prisma/client@6
```

---

### 问题 2：better-sqlite3 编译失败

**错误**：
```
gyp ERR! find Python
```

**原因**：`better-sqlite3` 需要 Python 编译，但生产环境已切换 PostgreSQL，不再需要 SQLite

**解决**：
```bash
npm uninstall @prisma/adapter-better-sqlite3 better-sqlite3 sqlite3
```
并修改：
- `prisma.service.ts`：移除 adapter
- `seed-test-data.ts`：移除 adapter

---

### 问题 3：Flutter SDK 版本不匹配

**错误**：
```
The current Dart SDK version is 3.12.0.
Because plant_story requires SDK version ^3.12.2, version solving failed.
```

**原因**：Docker 镜像 Dart 3.12.0，但 `pubspec.yaml` 要求 3.12.2+

**解决**：修改 `client/pubspec.yaml`：
```yaml
environment:
  sdk: ^3.12.0  # 从 ^3.12.2 降低
```

---

### 问题 4：Nginx 重复 location 定义

**错误**：
```
nginx: [emerg] duplicate location "/health"
```

**原因**：`nginx.conf` 中定义了两次 `/health` 路径

**解决**：删除底部重复的 `/health` 定义

---

### 问题 5：前端健康检查 IPv6 问题

**现象**：前端容器显示 `unhealthy`，但手动访问 `http://localhost/health` 返回 200

**根因**：
```
Connecting to localhost ([::1]:80)...
```
容器内 `localhost` 解析为 IPv6 `[::1]`，但 Nginx 只监听 `0.0.0.0:80`（IPv4）

**解决**：修改 `docker-compose.yml`：
```yaml
healthcheck:
  test: ["CMD-SHELL", "wget --no-verbose --tries=1 --spider http://127.0.0.1/health || exit 1"]
```
